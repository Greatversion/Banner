# GitHub Profile Setup

1. Create a **public repository named exactly your GitHub username**.
2. Copy `README.md` to the repository root.
3. Copy the complete `assets/` folder beside it.
4. Replace every `YOUR_GITHUB_USERNAME` with your actual GitHub username.
5. Replace the LinkedIn URL with your real profile URL.
6. If you want to show a real pub.dev package link, replace the generic pub.dev link with the package URL.
7. Commit and push. GitHub will automatically render the profile README.

## Recommended repository structure

```text
.
├── README.md
├── SETUP.md
└── assets/
    ├── header.svg
    ├── divider.svg
    └── tech-stack.svg
```
